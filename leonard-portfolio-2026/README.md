
# Leonard Phokane Portfolio

An interactive developer portfolio built with **Streamlit** and deployed on **Streamlit Cloud**.  
This portfolio showcases my skills, experience, and featured projects in AI/ML, Full‑Stack Engineering, and Cloud‑Native DevOps.


---

## 🚀 Features



- **Profile Section**: Professional headline, bio, and profile picture.
- **Skills with Metrics**: Visual progress bars for technical skills.
- **Experience & Education**: Career timeline and academic background.
- **Featured Projects**:
  - Cloud & DevOps Internship Project
  - Machine Learning Internship Project
  - Fullstack Internship App
  - Payment Service API (Independent Project, Ongoing)
- **Contact Section**: Email, LinkedIn, GitHub, and location.
